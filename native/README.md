# Native performance tooling

No native source or build definition has been imported.

Give each tool or library its own directory, including source, headers, build configuration, and a README. Record the Android NDK version, minimum API level, supported ABIs, dependencies, and execution privileges.

For daemons, document startup, shutdown, configuration, logging, and restoration of changed controls. Check available kernel interfaces, handle failed writes, and avoid repeatedly applying unchanged settings.

Keep runtime tuning separate from measurement so performance claims can be reproduced.
